## 本書の位置づけ

本アプリは **SCM / 物流管理システム案件の技術スタック(Java / Spring / MyBatis / jQuery / JUnit)を
ローカルで学習する**ことを目的とした教材です。
実運用を想定したシステムではないため、認証・認可、排他制御、監査ログ、帳票などは対象外としています
(詳細は [01-system-overview.md](01-system-overview.md) の「対象外事項」を参照)。

## 記述の前提

- 対象バージョン: `scm-study` 0.0.1-SNAPSHOT
- 仕様書中のファイルパスは、リポジトリルートからの相対パスです。
- 本書の内容は実装(ソースコード)を正とし、実装と差異が出た場合はソースコードを優先します。
