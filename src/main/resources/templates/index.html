この学習アプリでできること

  • アノテーション方式の Mapper: ItemMapper.java(@Select / @Insert / <script>動的SQL)
  • XML 方式の Mapper: StockMapper.xml(resultMap / association / include)、 ShipmentMapper.xml(collection / foreach / choose)
  • 独自 TypeHandler: 出荷ステータスの enum ⇔ コード値変換
  • トランザクション: 出荷引当(在庫減算＋ステータス更新)を1トランザクションで実行
  • JUnit 5: @MybatisTest による Mapper 単体テストと、サービスの結合テスト
  • jQuery: 商品検索・在庫入庫・出荷ステータス操作を Ajax で実行
